# Vista Locks Shop
**Vista Locks** is an e-commerce product showcase website for premium door locks and security hardware.

## Problem Statement
Customers looking for quality door locks often struggle to find a simple and clear online store that displays products with prices and ratings in an organized way.
## Solution
Vista Locks provides a clean product showcase where users can easily view different types of door locks, including smart locks, cylinder locks, bathroom locks, door handles, and door stoppers.
## Features
- Responsive product grid using CSS Grid
- Product cards with:
  - Product image
  - Title
  - Price
  - Rating stars
  - Add to Cart button
- Sticky navigation header
- Hero section with call-to-action
- Footer with contact information
- Hover effects on product cards and buttons
